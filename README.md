# Food Vendor, Shawarma & Bakery Ordering System

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2FOlumidenana%2Ffood-vendor-ordering)

A lightning-fast, mouthwatering mobile ordering system built for **Shawarma Stands, Doughnut Bakers, Grills, and Fast-Casual Food Vendors**.

### Features:
- 🌯 **Visual Food Menu**: Delicious photos, descriptions, and dynamic item counters.
- 🧀 **Custom Toppings & Extras**: Support for extra sausage, double cheese, spicy drizzle, and box assortments.
- 🛵 **Delivery vs. In-Store Pickup**: Dynamic delivery fee calculation and address input.
- 💳 **Paystack Payment**: Stops fake bank transfer screenshot scams before food is made.
- 📊 **Google Sheets Sync**: Automated kitchen logbook with exact item breakdown.
- 🔔 **Instant Kitchen Alerts**: Telegram Bot alert and direct 1-click WhatsApp messaging.
- 🛠️ **Vendor Admin Portal**: Live kitchen order tickets at `/admin`.
